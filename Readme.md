# 🛡️ AI HSE Analytics: Система предиктивной безопасности

**Интеллектуальная экосистема для департаментов ОТиПБ (HSE)**, позволяющая перейти от реактивного учета инцидентов к проактивному предотвращению аварий. Проект объединяет глубокий анализ данных, предиктивное моделирование и NLP-автоматизацию.

---

## 🚀 Основные возможности (ТЗ: F-01 — F-14)

### 📊 Модуль А: Аналитический дашборд (Frontend)
* **F-02 & F-05: Паттерны и Статистика** — Автоматическое выявление опасных временных интервалов (часы пик, дни недели) и аномальных локаций.
* **F-03: Анализ корневых причин (NLP)** — Кластеризация текстовых описаний инцидентов (TF-IDF + K-Means) для поиска скрытых системных проблем.
* **F-06: Предиктивная модель** — Прогноз частоты НС на горизонт до 12 месяцев с использованием градиентного бустинга.
* **Explainable AI (SHAP)** — Интерпретация решений модели: визуализация факторов, которые сильнее всего влияют на рост риска.

### 🛑 Модуль B: Аналитика «Карт Коргау»
* **F-12: Рейтинг безопасности** — Динамический рейтинг организаций в формате «светофора» на основе накопленного риска.
* **F-13: Матрица корреляции** — Математическое доказательство связи между мелкими нарушениями в Коргау и реальными травмами.
* **F-11 & F-14: Система Алертов** — Автоматическая генерация критических уведомлений (**Alerts**) и предупреждений о росте рисков (**Pre-alerts**).

### ⚡ Модуль C: Smart API (Backend MVP)
* **NLP-Классификатор** — Автоматическое извлечение сущностей (NER) и заполнение полей отчета из текста.
* **Векторные рекомендации** — Поиск наиболее релевантных мер контроля из исторической базы на основе семантической близости.

## 💻 Инструкция по развертыванию

### 1. Подготовка
В корневой директории проекта (`kmg/`) выполните:

```bash
# Создание и активация окружения
python3 -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt
pip install fastapi uvicorn "setuptools<70" natasha
2. Запуск ML-сервера (Backend)
Обеспечивает работу NLP-эндпоинтов (классификация и рекомендации).

Bash
uvicorn server:app --host 0.0.0.0 --port 8504
Swagger UI: Доступен по адресу http://localhost:8504/docs

3. Запуск Дашборда (Frontend)
В новом окне терминала (с активированным .venv):

Bash
streamlit run app.py
Интерфейс: Доступен по адресу http://localhost:8501

🧠 Логика предиктивной модели
Для прогнозирования используется модель CatBoost.

Признаки (Features): Семантические векторы из карт Коргау, частота нарушений по категориям, историческая интенсивность работ.

Целевая переменная (Target): Вероятность наступления инцидента в краткосрочном периоде.

Интерпретация: Благодаря SHAP мы видим не просто «процент риска», а конкретные причины: например, «Риск 85% вызван аномальным ростом нарушений при работе на высоте за последнюю неделю».
